Every layer is cut to its own tip depth with the cutter it was given, so every layer carries its own tool, feeds and speed. Safe Z is measured from the dial face. Consecutive layers set to the same tool number are cut without a change between them. A speed of 0 runs that layer with the spindle stopped.
Arc Fitting
?How far a fitted G2/G3 arc may stray from the path it replaces. Curved passes come out as a handful of arc blocks instead of thousands of short straight ones, which is what lets a control hold the feed through them. Set to 0 to write straight moves only.
Program
?Where the program's zero sits, measured from the centre of the dial face. At 0, 0, 0 the file is written about the dial centre with Z0 on the face. Setting Z to −0.6 puts zero 0.6 mm below the face — on the fixture, say — so the face is then cut at Z0.6.
Written for Fanuc, Haas and LinuxCNC: a full safety line, G43 tool length offsets, G64 blended motion and G30 park before every tool change. A GRBL-class controller will not accept G43 H or G64.
